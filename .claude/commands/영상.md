# 영상 자막 생성 스킬

영상 파일에서 음성을 인식해 자막을 생성하고, 영상에 하드코딩하는 작업을 수행합니다.

## 사용법

```
/영상 [영상파일경로]
```

## 작업 순서

### 1단계: 도구 설치 확인
- `ffmpeg`: 영상 프레임 추출 및 재조합
- `openai-whisper`: 음성 → 텍스트 변환 (자막 생성)
- `Pillow`: 프레임에 자막 텍스트 합성

```bash
# 설치 명령어
brew install ffmpeg
pip3 install openai-whisper Pillow
```

### 2단계: 자막 생성 (Whisper)

```bash
~/.local/bin/whisper "영상파일.mp4" --language ko --model small --output_dir "출력폴더/"
```

- 생성 파일: `.srt` (자막+타이밍), `.txt` (텍스트만), `.vtt` (웹용)
- 한국어 영상은 `--language ko`, 영어는 `--language en`
- 정확도가 낮으면 `--model medium` 또는 `--model large` 사용

### 3단계: 자막 수정

생성된 `.srt` 파일을 열어 텍스트 및 타이밍 수정:

```
1
00:00:00,000 --> 00:00:02,000
자막 내용
```

화자 표시가 필요하면 `[이름] 내용` 형식으로 작성.

### 4단계: 영상에 자막 하드코딩 (Pillow 방식)

ffmpeg에 libass/freetype이 없을 때 사용하는 방식:

```python
import re, os, subprocess
from PIL import Image, ImageDraw, ImageFont

SRT = '자막파일.srt'
INPUT = '입력영상.mp4'
OUTPUT = '출력영상.mp4'
FRAMES_DIR = '/tmp/frames'
FFMPEG = '/opt/homebrew/bin/ffmpeg'
FONT_PATH = '/System/Library/Fonts/AppleSDGothicNeo.ttc'
FONT_SIZE = 54  # 글씨 크기

os.makedirs(FRAMES_DIR, exist_ok=True)

def parse_srt(path):
    with open(path, encoding='utf-8') as f:
        content = f.read()
    pattern = r'\d+\n(\d{2}:\d{2}:\d{2},\d{3}) --> (\d{2}:\d{2}:\d{2},\d{3})\n([\s\S]+?)(?=\n\n|\Z)'
    subs = []
    for start, end, text in re.findall(pattern, content.strip()):
        def ts(t):
            h, m, s = t.split(':')
            s, ms = s.split(',')
            return int(h)*3600 + int(m)*60 + int(s) + int(ms)/1000
        subs.append((ts(start), ts(end), text.strip().replace('\n', ' ')))
    return subs

def get_fps():
    r = subprocess.run([FFMPEG, '-i', INPUT], capture_output=True, text=True)
    for line in r.stderr.split('\n'):
        if 'fps' in line and 'Video' in line:
            m = re.search(r'(\d+(?:\.\d+)?) fps', line)
            if m:
                return float(m.group(1))
    return 24.0

# 1) 프레임 추출
subprocess.run([FFMPEG, '-i', INPUT, '-q:v', '2', f'{FRAMES_DIR}/frame_%06d.png', '-y'],
               check=True, capture_output=True)

frames = sorted(f for f in os.listdir(FRAMES_DIR) if f.endswith('.png'))
fps = get_fps()
subs = parse_srt(SRT)
font = ImageFont.truetype(FONT_PATH, FONT_SIZE)

# 2) 자막 합성
for i, fname in enumerate(frames):
    t = i / fps
    text = next((txt for s, e, txt in subs if s <= t <= e), None)
    if text:
        path = os.path.join(FRAMES_DIR, fname)
        img = Image.open(path)
        draw = ImageDraw.Draw(img)
        w, h = img.size
        bbox = draw.textbbox((0, 0), text, font=font)
        x = (w - (bbox[2] - bbox[0])) // 2
        y = h - (bbox[3] - bbox[1]) - 40
        for dx in [-2,-1,0,1,2]:
            for dy in [-2,-1,0,1,2]:
                draw.text((x+dx, y+dy), text, font=font, fill='black')
        draw.text((x, y), text, font=font, fill='white')
        img.save(path)

# 3) 재조합
subprocess.run([
    FFMPEG, '-framerate', str(fps), '-i', f'{FRAMES_DIR}/frame_%06d.png',
    '-i', INPUT, '-map', '0:v', '-map', '1:a',
    '-c:v', 'libx264', '-pix_fmt', 'yuv420p', '-c:a', 'copy', '-y', OUTPUT
], check=True, capture_output=True)

print(f"완료! → {OUTPUT}")
```

## 주의사항

- Whisper `small` 모델 다운로드: 약 461MB (최초 1회)
- 프레임 추출 후 처리하므로 디스크 여유 공간 필요 (영상 길이에 따라 수백MB)
- 한국어 인식률: `small` < `medium` < `large` 순으로 정확도 향상
- 화자 구분은 자동으로 되지 않으므로 `.srt` 수동 수정 필요

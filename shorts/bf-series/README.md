## 공통 포맷

- 길이: 45~55초, 9:16 세로
- 오프닝 시그니처: "현장 문제? 천반장이 잡는다!"
- 클로징 시그니처: "설계부터 본인증까지, 천반장이 원스톱으로 해결합니다. 구독하고 현장에서 봅시다!"
- 자막: 자동 생성 단계에서는 넣지 않음 — 사용자가 영상 검수 후 직접 작업
- 톤: 현장 반장 특유의 시원시원하고 자신감 있는 말투. 전문용어는 반드시 한 줄 풀이 동반

## 제작 파이프라인

전체 파이프라인은 `/쇼츠` 스킬(`.claude/commands/쇼츠.md`)로 자동화되어 있다.
`/쇼츠 [주제와 내용]` 한 번이면 기획 → 스크립트 → 나레이션 → 장면 생성 → 조립까지 자동 진행되고
완성된 `final.mp4`가 전달된다. 자막과 유튜브 업로드는 사용자가 검수 후 직접 진행.

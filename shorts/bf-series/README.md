## 공통 포맷

- 길이: 45~55초, 9:16 세로
- 오프닝 시그니처: "현장 문제? 천반장이 잡는다!"
- 클로징 시그니처: "설계부터 본인증까지, 천반장이 원스톱으로 해결합니다. 구독하고 현장에서 봅시다!"
- 자막: 전체 하드코딩 (기존 `/영상` 스킬 활용), 핵심 수치는 화면 텍스트로 강조
- 톤: 현장 반장 특유의 시원시원하고 자신감 있는 말투. 전문용어는 반드시 한 줄 풀이 동반

## 제작 파이프라인 (1편 기준)

1. **나레이션 생성**: `generate_audio` (text2speech) + 천반장 목소리 element → 45~55초 mp3
2. **장면 이미지/영상 생성**: 스크립트의 장면표 기준, 프롬프트에 `<<<5e8c9770-3178-45b1-8d35-e541dea4ad92>>>` 삽입해
   천반장 등장 컷 생성 (`generate_image` → `generate_video`), 자료 컷은 일반 생성
3. **조립**: ffmpeg으로 장면 클립 + 나레이션 합성, 9:16 확인
4. **자막**: `/영상` 스킬로 Whisper 자막 생성 → 하드코딩
5. **검수**: 수치(등급 기준, 경사로 기울기 등) 최종 팩트체크 후 업로드
